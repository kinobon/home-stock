# Project: Home Stock App

## Stack
Vite, Solid.js, PWA, TypeScript, Tailwind

## Commands
- `pnpm dev`: dev server
- `pnpm lint:fix`: lint fix
- `pnpm format`: code format

## Rules
- Please note that it is SolidJS, not React.
- Please commit periodically between implementations.
